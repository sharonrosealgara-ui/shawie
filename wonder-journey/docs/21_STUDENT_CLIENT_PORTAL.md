# 🎒 Wonder Journey OS — Student / Client Portal

- **Version:** 1.0 · **Status:** Active (core live) · See ADR-011 (two portals)

> The learner-facing portal — simple, beautiful, immersive. One portal serves
> **families, parents, children, students, homeschool clients, tutoring clients,
> and learning-center clients** (there is no separate "Family Portal").

## Live today ✅
Home Base · Today's Adventure ("Up Next") · **Adventure Theater** (fullscreen
cinematic lessons) · Morning Blessings + Prayer Leader · Adventure Map · Passport ·
Badges · Adventure Tree · **Cooking Academy** · Family/Student Cookbook (keepsakes)
· Family/Student Storybook · Celebrations (birthdays · milestones · memory timeline
· certificates) · quizzes · reflections · progress (XP/levels) · Settings (family
roster, faith toggle, Sound Studio, theme).

## Roadmap 🔜
Little Chef Passport · Grandma's Recipe Box (when enabled) · Memory Gallery ·
videos · homework · calendar · messages · resources — added as modules mature
(most need uploads/storage from the SaaS phase).

## Hard rules (never shown here)
Teacher timer · teacher notes · answer keys · curriculum editor · admin tools ·
billing · automation/technical settings. **Live Class Mode (SaaS):** teacher clicks
Start Adventure → learners see only the fullscreen lesson experience; the teacher
sees presenter view + controls.

## Design bar
Storybook warmth per the [Design Bible](01_DESIGN_BIBLE.md) — the interface
disappears, the adventure remains.
