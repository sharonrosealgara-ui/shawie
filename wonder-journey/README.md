# 🌏 Wonder Journey OS — World 1: The Philippines

A gamified family learning adventure built for the **Ferrell Family**. Every
Adventure weaves together the family's priority subjects so learning feels like
one joyful journey, not separate school subjects.

## How to open it
- **On your computer:** double-click **`index.html`** — it opens in your browser and works fully offline. Progress saves automatically in that browser.
- **Online (shareable link):** deploy this `wonder-journey` folder to Vercel or Netlify (no build step needed) and add a custom domain.

## What's inside (World 1)
Five complete, ready-to-teach Adventures:
1. **Mabuhay! Welcome to the Philippines** — greetings, geography, the flag, gratitude
2. **Island Explorers** — Luzon, Visayas, Mindanao + directions & map math
3. **Kitchen Adventure: Champorado** — cooking, fractions & kitchen safety
4. **Bayanihan** — Filipino values, teamwork, respect for elders
5. **Fiesta!** — festivals, music, rhythm & joy

Each Adventure includes: 🌍 Geography · 📖 English · ➕ Math · 🗣️ Tagalog · 🗣️ Hiligaynon · 🔬 Science · 🍳 Cooking · 🎨 Arts · 🎵 Music · 🙏 Bible story *(optional)* · ❤️ Family discussion · 🤝 Character value — plus a **quiz**, **reflection**, **passport stamp**, **badge**, and **XP**.

## Gamification
- ⭐ **XP & Levels** (Explorer → Wonder Master)
- 🛂 **Passport** — a stamp for every Adventure
- 🏅 **Badges** — 10 to collect
- 🌳 **Adventure Tree** — grows as the family learns

## Built to be reusable & configurable (Settings)
- ✏️ **Family members** — edit names, roles & avatars
- 🙏 **Faith toggle** — one switch hides all Bible / Christian-character content for families who prefer a secular version
- 📦 **Backup & Restore** — export/import progress as JSON
- 🌙 Light / dark mode

## Tech
Self-contained static site — `index.html` + `curriculum.js` (content) + `app.js` (logic). No build step, no dependencies. Progress lives in the browser's local storage; the data layer is isolated so it can later move to a real database (Supabase/Firebase) for multi-device sync.
