# 🗂️ Wonder Journey — Asset Library

Authentic educational media lives here (see `REAL_MEDIA_POLICY.md`). **No hotlinking** —
images are stored locally (or in our cloud bucket). Drop **properly-licensed** files into
the matching folder using the paths in `media-manifest.js`; figures then activate
automatically (no code changes).

```
assets/
├─ philippines/
│  ├─ maps/            real maps: Philippines, Luzon, Visayas, Mindanao, regions, cities
│  ├─ landmarks/       Chocolate Hills, Rizal Park, Vigan, Mount Apo, Tubbataha, jeepney…
│  ├─ volcanoes/       Mayon, Taal, Pinatubo
│  ├─ beaches/         Boracay, Palawan, Siargao
│  └─ rice-terraces/   Banaue & other terraces
├─ animals/            Philippine eagle, tarsier, tamaraw, whale shark, carabao, clownfish
├─ food/              champorado, mango, lechon, rice cakes, rice…
├─ festivals/         Sinulog, Ati-Atihan, Panagbenga, kulintang, parol, sampaguita
├─ bible/
│  ├─ maps/           Bible-lands maps (real)
│  └─ locations/      Mount Sinai, Sea of Galilee, Jordan River, Bethlehem, Jerusalem, Egypt
├─ backgrounds/       original Wonder Journey scene art (illustration OK)
├─ mascots/           Sinag & friends (original illustration)
├─ stickers/          original stickers & scrapbook elements
└─ icons/             original UI icons
```

**Licensing:** record `credit` + `license` in `media-manifest.js` before shipping any
image. Prefer public-domain / open-license (Wikimedia Commons — verify each file;
OpenStreetMap exports — ODbL, attribute "© OpenStreetMap contributors"; NASA/USGS for
satellite/relief), or a clean paid license. Original illustrations belong only in
`backgrounds/`, `mascots/`, `stickers/`, `icons/`.
